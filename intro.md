# Machine Learning Engineer Notes

Interview-focused study notes for Machine Learning Engineer roles, organized as runnable Jupyter notebooks. Every code example is self-contained — you can execute any notebook top to bottom.

## Topics

**ML Coding Interview** — Implement ML algorithms from scratch in NumPy: linear models and gradient descent, classic algorithms (KNN, K-means, decision trees, naive Bayes), neural networks with backpropagation, attention and transformers, metrics and losses, and data processing utilities.

**ML System Design Interview** — A 7-step framework for ML system design questions, deep dives on each stage (problem framing, data and features, model selection, serving, evaluation and monitoring), and four fully worked case studies: feed recommendation, search and ads, fraud detection, and an LLM-powered RAG assistant.

**MLOps** — Why production ML is different, ML pipelines and versioning, training infrastructure and distributed basics, model serving and latency optimization, deployment patterns and rollbacks, monitoring, testing ML systems, and a Docker/Kubernetes quick reference.

**LLM Engineering** — The LLM landscape, transformer internals for inference (KV cache, RoPE, GQA, sampling), pretraining and fine-tuning (DPO, LoRA), inference optimization, RAG systems, prompting and agents, and LLM evaluation.

**MLE Interview Prep** — The interview loop and an 8-week study plan, project deep dive frameworks with example narratives, 25 trade-off questions with structured answers, and 6 worked debugging scenarios.

## How to use these notes

- Each section opens with **What Interviewers Test** so you know what to focus on.
- Code cells are runnable and use only numpy, pandas, matplotlib, scikit-learn, scipy, and PyTorch.
- Each notebook ends with **Common Interview Questions** and **Key Takeaways** for fast review before an interview.
